「小步腳印」隱私權政策

最後更新：2026-09-14

我們是誰

「小步腳印」是協助家長記錄兒童早期療育觀察的工具。我們深知孩子的發展紀錄屬於高度敏感的個人資料，本政策說明我們蒐集什麼、如何使用、以及你如何掌控這些資料。

我們蒐集的資料

1. 帳號資料：登入方式對應的識別資訊（Email 或匿名帳號 ID）。
2. 孩子資料：你主動填寫的名字/暱稱、出生日期、預產期、觀察標籤、備註與大頭照。
3. 語音紀錄：你錄製的音檔（僅在轉錄期間暫存）、自動產生的逐字稿與整理結果。
4. 照片：你為某筆紀錄附加的照片（例如治療師提供的教材）。
5. 使用紀錄：里程碑標記、回家練習打卡、訂閱狀態。
我們不蒐集裝置通訊錄、位置資訊或廣告識別碼。

資料如何使用

資料僅用於提供 App 功能：語音轉文字與內容分析、發展里程碑追蹤、統計圖表、回診摘要產生、家人共享。我們不會將你或孩子的資料用於廣告，也不會出售給任何第三方。

第三方服務（資料處理者）

為提供服務，資料會經過以下服務處理。我們只傳送提供該功能所必需的最少資料：
・Supabase（資料庫與檔案儲存）：儲存帳號、孩子資料、逐字稿、整理結果與照片，以及轉錄期間暫存的音檔。
・OpenAI（語音轉文字與內容整理）：只有兩樣東西會傳送至 OpenAI API——你錄製的音檔（用於轉成文字），以及轉出的逐字稿（用於整理成結構化紀錄）。孩子的姓名、生日、診斷標籤、照片與你的帳號資料都不會傳送給 OpenAI；但你在錄音中說出的內容（例如孩子的名字）會包含在音檔與逐字稿裡。依 OpenAI API 資料使用政策，透過 API 傳送的資料不會被用於訓練模型。
・RevenueCat 與 Apple（訂閱管理）：處理購買與訂閱狀態，我們不會接觸你的付款資訊。
・Sentry（崩潰與錯誤診斷）：App 發生錯誤或崩潰時，傳送技術性的診斷資訊（錯誤訊息與程式呼叫堆疊）協助我們修復。我們已設定不傳送個人識別資訊、不錄製畫面，並過濾掉逐字稿與孩子姓名等內容；診斷資料儲存於美國。

你的同意

在這台裝置上第一次錄音之前，App 會在畫面上說明上述傳送內容、對象與保留方式，你按下「我了解並同意」之後才會開始錄音；未同意就不會有任何音檔離開你的裝置。錄音鈕下方也會持續顯示這項說明與本政策的連結。你可以隨時刪除孩子的資料或刪除帳號，以撤回已提供的資料。

錄下他人說話時（治療師、醫師）

App 提供「錄下治療師或醫師的說明」這個功能，方便你把專業人員交代的事記下來。這種錄音會包含對方的聲音與談話內容，那屬於他個人的資料，因此：
・請務必在錄音前取得對方同意。App 在你第一次選擇這類錄音時會提醒你。
・部分醫療機構有禁止錄音的規定，請一併確認。
・這些音檔與逐字稿同樣會傳送至 OpenAI API 轉成文字，與你自己的錄音一樣的處理方式。
・你可以隨時刪除該孩子的全部資料，或使用「刪除帳號」永久移除全部資料。
・自動轉錄可能有誤，請以專業人員的原話為準。這些紀錄不構成醫療指示。

家人共享

只有在你主動產生邀請碼並由對方兌換後，受邀家人才能看到該孩子的紀錄。你可以隨時在「孩子設定」移除成員或退出共享。

資料保存與刪除

音檔只在轉錄期間暫存於伺服器，轉錄完成後立即刪除；保留的是逐字稿、整理結果與你附加的照片，這些會保存到你刪除為止。你可以隨時：
・在紀錄詳情頁長按刪除附加的照片；
・在「孩子設定」刪除單一孩子的全部資料（含所有紀錄）；
・使用「匯出全部紀錄」取回你的資料副本；
・在「孩子設定 → 資料與隱私」使用「刪除帳號」，永久刪除帳號與所有相關資料，此動作無法復原。

兒童隱私

本 App 的使用者是家長或監護人，孩子的資料一律由監護人輸入與管理。我們不會直接向兒童蒐集資料。

資料安全

所有傳輸均使用 HTTPS 加密；資料庫層級啟用列級安全性（Row Level Security），確保每位使用者只能存取自己與被授權共享的資料。

政策變更與聯絡方式
