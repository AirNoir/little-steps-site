帳號

一定要註冊才能用嗎？

不用。在登入頁選「訪客體驗（不需登入）」就能直接開始，功能完全一樣。

但訪客帳號是綁在這台裝置上的，換手機或重裝 App 資料會不見。如果你打算長期記錄，建議改用 Apple 或 Google 登入。

怎麼讓另一半或長輩一起看孩子的紀錄？

在「孩子設定」裡找到那個孩子，點「邀請家人」產生邀請碼，把碼給對方。對方在自己的 App 裡輸入邀請碼就會看到同一個孩子的紀錄。

你隨時可以在成員列表把人移除。

換手機了，資料怎麼帶過去？

如果原本是用 Apple 或 Google 登入，在新手機用同一個帳號登入就會自動同步。

如果原本是訪客帳號，資料無法轉移。這是訪客模式的限制，因為它沒有可以認回來的身分。

錄音與分析

按了錄音卻沒反應，或出現「找不到麥克風」

先確認 App 有麥克風權限：iOS「設定」找到「小步腳印」，把「麥克風」打開。

如果權限是開的還是不行，可能是別的 App 正佔用麥克風（例如通話或錄音 App），關掉它們再試。重開 App 通常也能解決。

錄音錄到一半自動停了

這是單則長度上限。免費版單則 2 分鐘，Pro 是 5 分鐘。到上限會自動停止並直接送出分析，已錄到的內容不會丟掉。

轉出來的文字不太準

語音轉文字對背景噪音比較敏感。在安靜一點的環境、把手機拿近一些會明顯改善。

轉出來的內容和 AI 分析都可以手動編輯，在紀錄詳情頁直接改就好。

這週的錄音次數用完了

免費版每週 2 次，Pro 每週 20 次。額度每週重置。

次數用完不影響其他功能，里程碑標記、回家練習打卡、回診摘要都還能正常使用。

訂閱

怎麼取消訂閱？

訂閱是透過你的 Apple ID 收費，取消要在 iOS 設定裡操作，不是在 App 裡。

路徑是「設定」點最上面你的名字，再點「訂閱」，找到小步腳印然後取消。取消後到本期結束前都還能用 Pro 功能。

換手機後 Pro 不見了

打開付費牆頁面，點下方的「恢復購買」。只要是用同一個 Apple ID 買的就會找回來。

要退費怎麼辦？

訂閱是 Apple 收款的，退費要向 Apple 申請，我這邊沒有權限處理。到 reportaproblem.apple.com 用你的 Apple ID 登入後提出申請。

如果是因為 App 有問題導致你想退費，也歡迎先寫信告訴我，也許我能直接修掉。

資料與隱私

孩子的錄音存在哪裡？誰看得到？

音檔存在私有的雲端儲存空間，資料庫啟用列級安全性，只有你的帳號和你主動邀請的家人能讀取。

語音轉文字與內容分析會把音檔傳給 OpenAI 的 API 處理。依 OpenAI 的 API 政策，這些資料不會被用來訓練模型。完整說明見隱私權政策。

怎麼把我的紀錄匯出帶走？

在「孩子設定」裡有「匯出全部紀錄」，會產生一份包含所有孩子資料、語音紀錄與里程碑的檔案。

怎麼永久刪除帳號和所有資料？

在「孩子設定」頁往下找到「刪除帳號」。會有兩段確認，確認後會永久移除你的帳號、所有孩子資料、錄音與紀錄。

這個動作無法復原，建議刪除前先用「匯出全部紀錄」留一份備份。

刪除帳號會取消我的訂閱嗎？

不會。訂閱由 Apple 管理，刪除 App 內的帳號不會自動取消訂閱。要取消請照上面「怎麼取消訂閱」的步驟到 iOS 設定操作。

使用上的觀念

早產寶寶的年齡怎麼算？

在孩子資料裡填了預產期，App 會自動用矯正年齡來推薦里程碑項目，不會拿實際出生日期去比對同齡基準。

里程碑沒達成是不是代表發展有問題？

不是。里程碑是觀察的參考範圍，每個孩子的節奏差異很大，單一項目沒達成不代表什麼。

這個 App 是觀察輔助工具，不是診斷工具。如果你對孩子的發展有疑慮，請帶著紀錄去兒童發展聯合評估中心讓專業人員評估。
